# Mara · Estética y Cuidado Corporal 🌸  
Portal web de servicios de belleza, bienestar y cuidado personal

---

## 📋 Descripción

**Mara** es una aplicación web diseñada para presentar y gestionar los servicios, productos y promociones de un centro de estética y cuidado corporal.  
El proyecto ofrece una experiencia moderna, elegante y visualmente coherente con la identidad de la marca, permitiendo a los usuarios:

- Explorar tratamientos faciales, corporales, masajes y servicios de belleza  
- Consultar productos premium  
- Realizar reservas de citas  
- Acceder a un área personalizada (usuarios registrados)  

El diseño se basa en tonos tierra, rosados suaves y tipografías elegantes, transmitiendo bienestar, calma y profesionalidad.

## 🚀 Características principales

### Para visitantes

- Consulta de servicios por categorías  
- Visualización de productos premium  
- Información detallada de tratamientos  
- Formulario de contacto y reserva  

### Para usuarios registrados

- Perfil personal  
- Lista de “indispensables” (favoritos)  
- Notificaciones personalizadas  
- Gestión de datos personales  

### Diseño

- Estética moderna y elegante  
- Paleta de colores basada en tonos tierra y rosados  
- Tipografías profesionales  
- Componentes visuales coherentes y accesibles
