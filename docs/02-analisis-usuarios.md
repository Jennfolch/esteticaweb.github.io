# Análisis de Usuarios

## 👩‍💼 Administrador
<div style="background:#F0D8D4; padding:12px; border-radius:8px;">

## 👤 Cliente (visitante)
Puede:

- Consultar servicios  
- Ver promociones  
- Explorar productos  
- Acceder al formulario de reserva  

No necesita registro.

## 🧑‍💻 Usuario Registrado
Dispone de:

- Lista de “indispensables”  
- Notificaciones personalizadas  
- Edición de datos personales  
- Cambio de contraseña
