

# Tecnologías Empleadas

Para el desarrollo del proyecto se han seleccionado las siguientes herramientas:

* **Frontend**: HTML5, CSS3 y JavaScript.
* **Backend**: PHP y MySQL para la gestión de datos y usuarios.
* **Herramientas de Desarrollo**: Visual Studio Code, XAMPP y GitHub para el control de versiones.


# Prototipo Mockup

El diseño se ha realizado utilizando la herramienta **Visily**.

### Paleta de Colores
Refleja naturalidad, bienestar y calma:
* **Primario**: Tonos tierra y beige (`#D89A91`).
* **Secundario**: Mezcla de tonos suaves (`#F0D8D4`, `#AD5A4E`).
* **Botones**: Tonos oscuros contrastados (`#784139`).

### Tipografía
* **Primaria (Títulos)**: Playfair Display.
* **Secundaria (Cuerpo)**: Mulish.

### Elementos de la Interfaz
* **Cabecera**: Logotipo, barra de navegación y botón de login.
* **Contenido**: Sección Hero con Call-to-Action, catálogo de tratamientos y formularios de contacto.
* **Pie de página**: Redes sociales, mapa de ubicación e información legal.
