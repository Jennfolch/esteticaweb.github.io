# Mara, Estética y Belleza
## Propuesta Inicial - Jennifer Folch (DAW2)

Este proyecto consiste en el **diseño y desarrollo de una página web** para el centro de belleza Mara - Estética y Cuidado Corporal. El objetivo es dar a conocer servicios, productos y facilitar la reserva de citas en línea mediante una plataforma moderna y responsiva.

### Perfiles de Usuario
* **Administrador**: Gestión de contenidos (servicios, promociones) y control de reservas.
* **Cliente (visitante)**: Visualización de servicios y acceso a reservas sin registro.
* **Usuario registrado**: Perfil personal para guardar "indispensables" y recibir promociones personalizadas.
